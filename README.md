# Two-Stage-Spur-Gear-Reducer-Gearbox-SolidWorks-
Two-Stage Spur Gear Reducer Gearbox in SolidWorks (MMGS, ANSI Metric, Module 2, 13.36:1 ratio). Includes 13 native .SLDPRT parts (21 instances) with ribbed split casings, keyed input shaft, bearings, snap rings, 17:56 &amp; 18:73 gear mates, and a movable left casing for axial disassembly.
